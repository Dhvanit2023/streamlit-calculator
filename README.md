# Streamlit Calculator

A simple original-calculator-style web calculator built with Python and Streamlit.

## Features
- Addition, subtraction, multiplication, division
- Percentage
- Square root
- Decimal numbers
- Parenthesis-ready calculation engine
- Backspace
- Clear
- Calculation history
- Calculator-style dark UI
- Responsive Streamlit layout

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL shown by Streamlit, normally:
http://localhost:8501
